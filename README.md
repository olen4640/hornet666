# Шершень666 — Density Screener

Первый прототип скриннера биржевых плотностей для MOEX.

## Что уже есть
- WPF-интерфейс на .NET 8.
- Демонстрационная таблица инструментов и заявок.
- Фильтр устойчивости: заявка считается неподвижной, если её цена не смещалась в пределах заданного допуска за окно наблюдения.
- Пометка круглых и полукруглых уровней через настраиваемый шаг разметки.
- Сортировка по расстоянию до рынка и размеру заявки.

## Важно
Это **UI/logic prototype с демонстрационными данными**, не подключённый к бирже скриннер. Здесь пока нет реального MOEX/CScalp/MetaScalp feed, исполнения ордеров или торговых сигналов. Следующий этап — согласовать формат источника стаканов и подключить поток данных.

## Запуск
Открыть `src/Hornet666.App/Hornet666.App.csproj` в Visual Studio 2022 с установленным .NET 8 SDK и собрать проект.

## Структура
- `src/Hornet666.App` — WPF-приложение.
- `src/Hornet666.App/Models` — модель плотности и демонстрационные данные.
